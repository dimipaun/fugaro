# Driving the wizard without a prompt

A surface — the console, a script — drives the same wizard the user runs at their terminal (step 1 of `SKILL.md`), with no prompt at all.

`--answers-file PATH` answers the five questions a first run asks — `--gcp-project`, `--location` or its precise form `--region`, `--name`, `--rigor` and `--bake-repos` — from one JSON document, which carries the document's version too; PATH is a file, or `-` for stdin. A flag given beside the file wins over it, and the run says which. The file answers questions and confirms nothing: the steps that are a person's — creating the GCP project, linking its billing, the permanent Firestore location, every secret value — have no member there and are still taken at a real terminal, so a `--json` run with a whole answers file applies only what needs no confirmation.

`--events`, which needs `--json`, writes the run to stdout as newline-delimited events instead of the one document: one `step` line as the run reaches a stage, one `stage` line as a stage settles, one `left_for_you` line for each thing only the user can do — with the one line to run — and one last line that ends the feed, `done` with the run's exit code or `error` naming the stage the run stopped at. A run that ends with steps left for you ends `done` with exit code 1: it did not fail, and the steps are the `left_for_you` lines above it.

The user runs that form too, in their own terminal window, not through the agent:

```bash user-runs
fugaro setup --answers-file <answers.json> --events --json
```

With `--plan-only` the same document plans the run and creates nothing — the read a surface shows before its apply.
