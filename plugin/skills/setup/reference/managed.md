# Managed projects: the flag for an existing one, and creation

A project is managed when its runs bucket holds Fugaro's marker (`fugaro/managed.json`): the creation fact, written by the run that created the project, or the flag an owner put on one that already existed. Only one whose marker records a budget can be applied, and flagging is the cure for the other kind: it replaces the creation fact that records no amount with the version that records one. The flag is the owner's, and it is the only way a project Fugaro did not create becomes managed.

**Flagging a project that already exists.** A project Fugaro did not create, or one it created without `--managed`, becomes managed by the same marker, and for such a project the only writer of it is the owner's flagging command, run in their own terminal window, not through the agent; it refuses an agent's session, and its confirmation is that project's exact GCP project ID typed by hand, which no flag stands in for. It records the monthly budget alert amount the owner states, and the amount and the currency are the user's decision: ask, never pick. Never run it yourself, and never write that marker any other way:

```bash user-runs
# flag an existing project as managed, recording its monthly budget alert amount
fugaro managed flag <gcp-project-id> --budget <amount> --budget-currency <code>
```

**Creating a managed project.** With init's `--create-project --managed`, the monthly budget amount is required: no default; without one nothing is created. Amount and currency are the user's decision, in their own terminal window, not through the agent: ask, never pick. `--billing-account` is the account charged; alerts fire at 50%, 90%, 100%. Both are recorded in its creation fact. On an existing project init warns `--managed` was not applied: flag that project instead, above. Without `--managed` the budget is optional and nothing is recorded. `fugaro restore` refuses an agent session: say so, stop, never rebuild it by hand ([docs/gcp-setup.md](https://github.com/dimipaun/fugaro/blob/main/docs/gcp-setup.md)).
