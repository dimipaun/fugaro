# A/B pairs

You are reading what a sampled launch produced, or explaining one of the two runs it started. The champion is a run like any other; the challenger is not.

Where the project samples runs (`ab.rate` in the published project layer), one launch starts two runs: the champion the developer sees and a challenger on another coder model — the same task at the same commit, a shadow that pushes nothing, opens no pull request and comments on nothing. Both records carry one pair ID and the same batch label — `ab-pair-<the champion's run ID>`, or the launch's own `--batch` label, which wins — so `fugaro runs ls --batch <label>` shows the pair.

- **A challenger is not the user's to follow up.** It owns no pull request, its outcome is `none`, and nothing is waiting on it: never read one as a run whose result went missing, never offer to continue it, and never launch a fix round for it. The work to continue is the champion's own pull request.
- **`fugaro ab --since 30d` is the results table**, one row per rigor mode, tier and model pair: pair counts, the challenger's wins, losses and ties, its win-share interval and cost ratio, halts and the advice. It scores the run records alone — no model call, no judgement: `--since` is how far back it reads (30 days by default), `--repo owner/name` narrows it, and `--json` prints the same rows as data. `no conclusion: too few decisive pairs` is not the same answer as keeping the champion: a row needs 20 decisive pairs to advise anything. It is part of Fugaro Enterprise: a build without it answers that this build does not include it.
- **The judge is a routine of its own, not yours to start.** `ab.judge_model` in the project layer names the model a pair's blind judge uses; the `ab-judge` recipe is the run that reads the pair's two patches as A and B and calls that model once per pass, twice with the order swapped (`fugaro run --recipe ab-judge`). It is one judge run per repository at a time, and it spends on the project's model credential: read the table rather than judging two diffs yourself.
