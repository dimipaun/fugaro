WHAT YOU GET

Pull requests, not promises

Every run that pushed ends in a pull request, a draft one if it failed. Fugaro never merges.

A pull request per task
A draft opens at the first push, marked not verified, and it is marked ready only when the run passes.
The diff and the report
What changed and what the run did, on the pull request.
The logs
In Fugaro's own log bucket, readable by launchers and operators.
The cost
Every stage has a dollar limit, on by default. Cloud Run bills a task only while it runs.
Your cloud, your laptop free
No Fugaro service in between. The container does not stay.
