Set the caps

Set a cap, the lease limit or the mode (budget admins)
fugaro budget set (--global | --defaults | --repo [owner/name]) [--daily USD] [--per-run USD] [--max-reserve USD] [--mode observe|enforce] | --clear
Show caps, today's counters, kill switches, headroom and the runs in flight
fugaro budget show
Estimate a batch's worst-case model spend against today's caps
fugaro budget preview --recipe NAME --runs N [--repo R]
Show the effective model price table, offline
fugaro budget prices
Halt every run of the project or of one repository (budget admins)
fugaro budget kill (--all | --repo [owner/name]) [--reason TEXT]
Clear a kill switch (budget admins)
fugaro budget resume (--all | --repo [owner/name]) [--reason TEXT]
