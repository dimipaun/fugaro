Checks run first when the recipe asks for them. The coder and the first-line reviewer go round for as many rounds as the recipe allows. Then the senior review judges the result; if it rejects, the work bounces back once, then the run fails. A draft pull request becomes ready only when the senior review ships it and the tests pass on the final commit.
