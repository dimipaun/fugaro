Fugaro Website Redesign Spec. Goal: the v1 site works but feels plain and has too much text. Make it punchy and visual, so a visitor gets the point of every page in seconds. Core principle: the gist above the fold: every page must state its main point above the fold with very few words (Getting Started shows the exact commands to run right at the top, up and running in 30 seconds). 1. Cut the text: all pages far too text heavy; rewrite short and scannable; long reference docs (e.g. the page made from SECURITY.md) can stay but each opens with a short summary of key points, detail below; remove the intro paragraphs that say the content is generated / not hand-typed (internal text, must not appear on public pages). 2. Accent colour: the current electric highlight colour does not match the logo; sample the exact hue from the logo file (brand/fugaro-logo.png) and build an electric high-energy accent from it; use it consistently. 3. Navigation: the top menu is too long, on mobile it wraps onto three rows; group items into a two-level menu (a few top-level sections with dropdowns) and a hamburger or drawer on mobile; on mobile the header must fit on one row. 4. How It Works page: rebuild graphical: a step-by-step visual flow (task submitted -> ephemeral Cloud Run job -> agent runs -> result / pull request), one line per step at most. 5. Sizzle: homepage terminal-style animation of a real Fugaro run (starting the task, the Cloud Run job spinning up, the pull request at the end); good images or diagrams showing how the system works; copy-to-clipboard button on every command or code block. 6. Mobile: layout renders fine today; keep it so; the main fix is the header and menu. Process: Playwright full-page screenshots of every page (desktop and mobile); screenshots + spec + logo to Claude Design for a graphic redesign; build it; screenshot again and compare until they match. Done when: the gist is above the fold on every page; no internal/meta text; accent matches the logo; mobile header fits one row; How It Works is visual and the homepage has the terminal animation; every command block has a copy button; final screenshots match the approved design.
