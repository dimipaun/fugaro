## Conventions

`CLAUDE.md` and the rules it loads: `.claude/rules/credentials-service.md` does not apply (no credential is read or written); `.claude/rules/terraform.md` applies to T-IS17. Hermetic tests only (`internal/testutil`, `internal/gcpfake` or a `file://` `blobx` bucket, `t.TempDir()`, an injected clock, environment, platform and `gh` runner); no network, no real home. **No secret-shaped literal** in a test, doc or fixture: build sample secrets from fragments. No live cloud action by an agent; every check below is owner-run. Docs are tested: edit a doc, run `go test ./internal/cli/ -run Docs`, keep the pinned fact. Comments explain why. A documented command change updates `plugin/skills` in the same PR (T-IS9). A wire or JSON shape a reader outside the binary consumes (`issue list --json`, `show --json`, the shared issue record) is versioned and never changes a field's meaning. Run targeted tests, never whole `internal/cli`. Release notes: any step after deploy goes in `### For operators` in that PR; the one change that needs the installation is T-IS17's grant, whose entry is "run `fugaro update`" and which `update` converges (tested at the previous version).
