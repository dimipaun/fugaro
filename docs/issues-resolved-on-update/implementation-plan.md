## Conventions

`CLAUDE.md` and the rules it loads: `.claude/rules/credentials-service.md` applies to the edits of `SECURITY.md` and `website/content/security.md` in T-RU7 (no credential is read or written otherwise); `.claude/rules/terraform.md` does not apply (no Terraform changes: the installation record is an object, like `fugaro/config.yaml`). Hermetic tests only (`internal/testutil`, `internal/gcpfake` with `gcpfake.NewGCS` for generation matching, an `httptest` server standing for GitHub, `t.TempDir()`, an injected clock, environment and agent-marker seam); no network, no real home. **No secret-shaped literal** in a test, doc or fixture. No live cloud or GitHub action by an agent; every check below is owner-run. Docs are tested: edit a doc, run `go test ./internal/cli/ -run Docs`, keep the pinned fact. Comments explain why. A wire or JSON shape a reader outside the binary consumes (the shared record, `update --json`) only gains fields with new names; the record's `status` gains a value and the record gains `closed_as`, which must ship with the first CLI that reads shared records (open item O2) or bump the record's version. Run targeted tests, never whole `internal/cli`. **The hard rule applies to every task that touches the update path:** `fugaro update` never fails, prompts or waits because of this feature, and an installation at the previous version converges (a test for it is in T-RU5).

## Slice 1: the parts that stand alone

### T-RU1: the GitHub issue reader and the release helper
- **Files:** `internal/issueresolve/github.go` (new), `internal/issueresolve/github_test.go` (new), `internal/updatecheck/updatecheck.go`, `internal/updatecheck/updatecheck_test.go`. **Interfaces:** consumed `net/http` through an injected client and base URL; `updatecheck`'s strict `X.Y.Z` parsing (the helper this task exports instead of a third copy of `semverRE`: `CanonicalRelease(s) (string, bool)` and `AtOrBelow(release, current string) bool`, a `dev` or unparseable current never matches); produced `Reader.ListClosed(ctx, lowest int) (map[int]State, error)` with `State` one of `ClosedCompleted{Milestone string}`, `ClosedNotPlanned`, `ClosedDuplicate`, `NoVerdict`, a typed `ErrRateLimited` for a 403 or 429 and a typed `ErrTransport` for a network failure. The URL is built from the `updatecheck.Repo` constant, `…/issues?state=closed&per_page=100&page=<n>`, newest first, at most five pages, stopping when a page's lowest number is below `lowest`; redirects are refused; each page body is bounded (512 KiB) and decoded as a typed list that **ignores the many other fields of a real GitHub issue object** (a strict decode would refuse every real response) keeping `number`, `state_reason`, `milestone.title` and the presence of `pull_request`; an item that is a pull request, an unknown reason or a milestone that is not a strict `X.Y.Z` (optional `v`) is `NoVerdict`. **Schema/rules/config change:** none. **Tests (a recorded, full GitHub issue-list page as the fixture, not a four-field one):** `TestListClosedDecodesARealPage`, `TestListClosedCompletedCarriesMilestone`, `TestListClosedNotPlannedAndDuplicate`, `TestListClosedNoVerdictForOddMilestone`, `TestListClosedPullRequestIsNoVerdict`, `TestListClosedRefusesRedirect`, `TestListClosedBoundsTheBody`, `TestListClosedRateLimited`, `TestListClosedTransportError`, `TestListClosedStopsAtFivePagesOrLowest`, `TestListClosedUsesTheRepoConstant`, `TestCanonicalRelease`, `TestAtOrBelow`. **Command:** `go test ./internal/issueresolve/ ./internal/updatecheck/ -run 'TestListClosed|TestCanonicalRelease|TestAtOrBelow' -count=1`. **Depends on:** nothing. **Commit:** `issueresolve: read the closed issues' state and milestone`. **Red step:** the first test fails to compile until the reader exists; then a body over the bound must fail. **Reviewer tier:** standard. Not OWNER-RUN.

## Slice 2: the pass

### T-RU4: the resolver pass
- **Files:** `internal/issues/resolve.go` (new), `internal/issues/resolve_test.go` (new). **Interfaces:** consumed T-RU1's `Reader`, T-RU3's `SetResolved`/`SetClosed`/`Reporters`, T-IS10's `ListShared`, `updatecheck.AtOrBelow`, `internal/safetext`, an injected agent-marker seam and clock; produced `Resolve(ctx, deps, installed string) (Result, error)` where `Result` is `{Fixed []Fixed, Quiet int, Skipped string}` and `Fixed` is `{Number, Summary, Release, URL, HitBy []string}`. It lists the shared issues in `submitted`, keeps those whose recorded GitHub URL has exactly the shape `https://github.com/dimipaun/fugaro/issues/<n>` (anything else is skipped), asks the reader once for the closed pages down to the lowest of their numbers, and for each: `ClosedCompleted` with a milestone at or below `installed` is fixed (marked `resolved` with `resolved_in` set to the milestone unless the agent marker says a coding agent's session, in which case it is returned and nothing is written); a milestone above `installed` is left for a later update; `ClosedNotPlanned` and `ClosedDuplicate` are marked `dismissed` with `closed_as` (the same guard) and counted in `Quiet`; an issue absent from the closed pages (open, transferred, deleted, older than the pages) or with `NoVerdict` is left alone; `ErrRateLimited` and the first `ErrTransport` end the pass; a total of 20 seconds bounds it and a `recover` wraps it; every failure becomes `Skipped` text, never an error a caller must handle. Names go through `safetext`, de-duplicated, capped at five plus a count. **Schema/rules/config change:** none. **Tests (a fake reader, a `gcpfake.NewGCS` store):** `TestResolveMarksClosedCompletedAtOrBelowInstalled`, `TestResolveLeavesMilestoneAboveInstalled`, `TestResolveNotPlannedAndDuplicateAreQuiet`, `TestResolveNoMilestoneNoVerdictStaysSubmitted`, `TestResolveStopsOnRateLimit`, `TestResolveStopsOnFirstTransportError`, `TestResolveNewIssuesAreNotStarvedByOldOpenOnes`, `TestResolvePanicIsSkipped`, `TestResolveIgnoresForeignURLShape`, `TestResolveAgentSessionWritesNothingButReturnsFindings`, `TestResolveReaderErrorIsSkipped`, `TestResolveAlreadyResolvedByAnotherMachineIsNotAnError`, `TestResolveHitByIsSafeAndCapped`, `TestResolveTimeBound`. **Command:** `go test ./internal/issues/ -run 'TestResolve' -count=1`. **Depends on:** T-RU1, T-RU3. **Commit:** `issues: resolve submitted issues the installed release fixes`. **Red step:** the first test fails until a closed-completed issue is marked; the agent-session test fails if the guard is removed (the mutation check). **Reviewer tier:** `opus + mandatory independent review` (network input decides a write to shared state). Not OWNER-RUN.
