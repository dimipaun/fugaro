- **A launcher's cloud access now covers the installation's shared issue store**, so an issue is filed with the credential of the person who files it, and no run's account can write one.

### For operators

1. Run `fugaro update`. It replaces each launcher's bucket grant with the one that also covers `issues/`, the prefix the shared issue store lives under, and names the launchers whose grant it replaces — with no `--allow-delete` and no second command.
