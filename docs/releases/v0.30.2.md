- **A launch starts again.** 0.30.0's credentials service refused every launch with `caller_not_admitted`, even for a person on the roster. The launch's ticket request, a Batch run's registration and `fugaro pair` now send your token the way the service reads it.

### For operators

Run `fugaro update`. It changes nothing for this fix.

### Known limits

- Run `brew upgrade dimipaun/tap/fugaro` first: 0.30.0 and 0.30.1 launch nothing against an installation on 0.30.
