## Highlights

- **`fugaro update` can build job images in us-east5.** The estimate that prices a Cloud Build read the region's E2 row with the wrong letter case, so every image build there stopped with "no price"; it now finds the row.
- **A build whose cost cannot be estimated no longer stops.** If the Cloud Billing catalog has no row for a build's machine and region, or cannot be read, the build runs uncounted after one warning, as one on an installation with no budget backend already did. Caps, kill switches and the budget database's own refusals are unchanged.

### For operators

1. Run `fugaro update` once per installation, on your own machine; it is the whole upgrade, and it brings back the image builds 0.22.0 stopped on. Nothing else to run, and it asks nothing.

### Known limits

- **An unpriced build is not counted against the budget.** The warning says so; the build's cost shows in Cloud Build's own billing until the catalog row is found.
