- `fugaro init` in 0.8.5 stopped when it created the managed deployer's custom role, because the role named a permission Google does not allow, so no installation could finish it; that is fixed.

### For operators

1. Upgrade the CLI (`brew upgrade dimipaun/tap/fugaro`), then run `fugaro upgrade` in each repository checkout so the plugin pin follows.
2. Re-run `fugaro init --firebase <gcp-project>` once per installation, in your own terminal. 0.8.5's `fugaro init` could not complete on any installation, so a new installation could not be created and an existing one could not re-run `fugaro init --firebase`.
3. An installation that never re-runs `fugaro init` needs nothing.
