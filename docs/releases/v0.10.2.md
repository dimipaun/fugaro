- **`fugaro watch --keep` and `--keep-count` now cover failed runs.** Before, a longer window kept successes on screen for longer but a failed run still left the list after three minutes, so raising the window made a failure less visible than a success.
- **A run is no longer falsely refused by the workflow guard.** The guard that keeps agents out of `.github/workflows` now drops an unreadable base on its own instead of dropping every base, so a run is not blamed for a workflow file that a base branch it merged in already carried. A run's own workflow edit is still refused when both bases are in play, and a test pins that.
- **`fugaro plan graph` refuses what it used to guess at.** A document from a schema version this build does not read is refused, `--done ""` is refused, and a refusal names the file you passed rather than the path written inside it.
- **The security page says what the credentials service's account can do.** Its database role can read and write the whole installation database, including the stop switches and the policy, because database access by role has no path scope; the service's audit trail also records the one refusal it used to leave unrecorded.

### For operators

1. **Per machine** — upgrade the CLI on every machine that runs Fugaro: `brew upgrade dimipaun/tap/fugaro`.
2. **Per repo checkout** — run `fugaro upgrade`, which pins the plugin to this release and refreshes the repository's job images.
3. Nothing in your cloud project changes by upgrading alone.

### Known limits

- **A graft file written by an agent can still get past the workflow guard's file list.** Git honours a graft file even with replace objects switched off; GitHub's missing `workflows` permission still stops the push, and the guard closes this in the next patch.
- **The release script's signal test fails on macOS.** It passes in CI on Linux; it only affects someone running the script's own tests on a Mac.
- **The credentials service stays dormant until an owner opts in**, and its live checks (94 to 96 and 99) have not been run.
