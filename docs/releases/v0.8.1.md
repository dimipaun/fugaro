- `fugaro validate` no longer halts on a layer's Claude claim the run would accept: a project layer that claims a model for a route the repository does not have, or overlaps one it has, is now judged exactly as the run judges it, so the false halts the 0.8.0 routing check could print are gone and the message names the real fix.
- A routed Claude pin's price problem is now reported once and against the right pin: when only `agent.model` is set, `validate` no longer prints the reviewer's missing price twice or words it for the wrong run.
- When `validate` cannot read your project config, the loader's own reason (and the fix it names) is printed first and the file path last, so a long path can no longer cut the instruction off.
- `fugaro watch` hides merged and closed pull requests from "Ready for your review" when `gh` is installed (`--no-pr-state` turns it off); without `gh`, or when it cannot tell, the list renders as before and says so.

### For operators

Upgrade the CLI (`brew upgrade dimipaun/tap/fugaro`, or this release's archive with its cosign check). There is no rollout step: no image rebuild, no rules deploy and no `init` is needed for this patch.
