- **`fugaro update` builds every job image.** An entry the project's image map names no repository for is built from its own catalog source repository, instead of failing the build.
- **Long catalog builds no longer hit Cloud Build's argument limit.** The clone step carries its files in short pieces, so `sandbox-web-gh` builds.
- **A Bitbucket repository's job image builds.** The clone step uses the build's own access instead of a token the build never receives.

### For operators

`brew upgrade dimipaun/tap/fugaro`, then `fugaro update`: it deploys the credentials service and rebuilds the images.
