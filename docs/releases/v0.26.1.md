- **`fugaro update` from 0.25.0 now finishes the installation step.** The first apply of 0.26.0's new project build account granted on the account before it existed, and the update stopped with a 404 on "Unknown service account". The grants on the build account, and the ones on the orchestrator's account that had the same shape, now wait for their account.
- **The daily catalog check names a git credential that exists.** On an installation where `fugaro secrets set github-app-key` had not written a `project_secrets` entry, the catalog check's grant named a secret container nothing created, and the update stopped on it. The check now uses the project's copy of the credential when the installation plans or already holds that container, and the repository's own copy otherwise.

### For operators

1. Run `fugaro update`. If your update of 0.26.0 stopped at the installation step, running it again resumes there and finishes; it asks nothing more than before.

### Known limits

- The installation's catalog check still prefers a repository's own copy of the git credential without checking that the copy holds a version; the per-repository check does check it.
