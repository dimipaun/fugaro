- **`fugaro update` no longer stops at the credentials service on a managed project.** 0.21.0's update ended at the installation step with "the minimum instance count is not known at plan time: write it out literally": the managed gate could not price the credentials Cloud Run service because its scaling was not written out. The service now states it (scale to zero, automatic scaling), and the gate no longer refuses the manual instance count the provider reports for an automatically scaled service. An installation whose update was refused with that message now goes through.

### For operators

1. Upgrade the CLI and run `fugaro update` again, as for 0.21.0. An update that stopped at the installation step with the message above now continues; there is nothing else to run.
