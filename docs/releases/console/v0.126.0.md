# Fugaro Console 0.126.0 "Yuzu"

Yuzu mounts the Manage section and the setup wizard, adds the Coordinator's graph of orchestrators, and makes
the numbers and refusals on every screen say where they came from. Screens that need a newer CLI than yours
show `n/a` with the cause instead of an empty cell.

- **Manage is on a screen.** Add a model or an image from a window that shows what will change, and a repository
  layer's settings write names the repository it writes to.
- **Set a project up from the console.** The setup wizard's screens walk a new project through its steps, and
  the rail and the project picker have an Add project entry.
- **The Coordinator is a graph.** The tab draws the active orchestrators and their plan tasks as a graph.
- **The Graph and Run screens say more.** The graph draws before the merge state is known, the Run screen shows
  the iterations bar and the source a run's model was served from, and a paused run has its own status word.
- **Pools have a screen.** The routing pools a project publishes are listed beside the models.
- **Every `n/a` names its cause**, a refusal keeps the path it was about, an identity is drawn whole, and the
  per-person spend breakdown is on by default.
- **Tabs open faster.** The Spend and Project tabs draw their rows as they arrive, and the other tabs are
  prepared after the first paint.
- **Download the build you need:** the `.dmg` (macOS, signed and notarised), or the AppImage or the
  `.deb` (Linux). The Linux artifacts are unsigned: an AppImage is not code-signed, there is no Linux
  signing key and none is planned; the SHA-256 in `console-sha256sums.txt` is what proves the bytes, and
  that file is signed with the Sigstore bundle beside it.

### Known limits

- **The screenshot goldens have not been re-recorded** (the owner's Checks 710 and 712), so the recorded images
  still show earlier screens. CI skips the goldens, so nothing fails.
- **The console's unit tests can time out on a loaded machine.** They pass when run alone or with
  `--maxWorkers=2`.
- **There is no Windows download.** The Windows installer is unsigned and is packed at release time only,
  attached to nothing.
