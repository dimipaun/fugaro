# Fugaro Console 0.120.0 "Quince"

Quince adds a way for administrators to edit the Project tab's settings from within the console: a little pencil icon on each setting the CLI's generic path writes, opening a window that shows what the edit will do before anything is written.

- **The Project tab now lists the project's settings, and each one you can edit carries a pencil.** A row shows the key, the scope it belongs to, the value a run gets, the layer that decided it and whether the layer was read; a row the CLI's own read says is writable carries a small **Edit** pencil whose name is the setting it edits, and pressing it opens a box for the new value — or, left empty, removes the key. A setting another command writes is drawn without a pencil and names that command instead, and a sensitive setting is not drawn at all: no key, no value and no pencil.
- **The window shows what will happen, and nothing is written until you confirm it.** The console first asks the CLI what the edit would do without writing anything, and the window draws the key, the old value, the new one, the layer the write lands in, the layer that wins and the exact command — plus a sentence when the edit will not change what a run reads. When the edit raises a limit the window shows the CLI's own sentence for it, **Cancel** is the default button, and **Confirm** needs the tick **I understand this raises a limit** first. That tick is the console's own extra confirmation of the edit, not a security control: what the CLI itself answers a widening with is `--yes`, which the console passes.
- **A refusal is shown in the CLI's own words.** If the file changed since the console read it, nothing is written, and the CLI's sentence appears beside a **Read again** control. The console never retries a write on its own.
- **Download the build you need:** the `.dmg` (macOS, signed and notarised), or the AppImage or the `.deb` (Linux, **unsigned**: an AppImage is not code-signed, there is no Linux signing key and none is planned; the SHA-256 in `console-sha256sums.txt` is what proves the bytes, and that file is signed with the Sigstore bundle beside it). There is no Windows download.
- **Nothing to run after this release.** There is no operator step and no rollout order here: the console edits files a person could edit with an editor, and the new CLI flags and fields only add to what was there.

### Known limits

- **Launching is no longer the console's only write.** A confirmed edit spawns `fugaro settings set|unset`, at the layer the CLI's read named and only for the rows that read says are writable; every control on the Project screen that was drawn disabled stays disabled.
- An edit does not change a run until `fugaro update` publishes it: the console shows the CLI's own `next: fugaro update` line after a successful edit and never runs it.
- The pencils appear only with a CLI whose settings read says which rows are writable — Fugaro 0.17.0 or later. On an older CLI the settings section is drawn with no pencils.
- Windows comes in a later release.
- The Fugaro Subscription Terms that the licence refers to may not be published yet.
