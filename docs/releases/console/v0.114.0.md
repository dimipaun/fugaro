# Fugaro Console 0.114.0 "Orange"

You can now launch a run from the console, and the Live view shows, project by project, what is running and how much of today's cap it has used.

- **Launch a run from the Live view:** pick one of the repositories your installation has recorded, write the task, and confirm it in a separate window whose Yes counts only after a short pause, so a stray double-click never starts a run.
- **A redesigned Live view:** a fleet budget panel shows the global cap, what the cap has counted and the headroom left, and each repository has its own panel with a runs table and a five-step pipeline for every run.
- **Leased spend on the cap bar:** with Fugaro 0.13.0 or later, the cap bar splits what is counted into money already spent and money leased to runs still working but not yet spent.
- **Spend by rigor mode:** with Fugaro 0.13.0 or later, the Spend screen groups spend by the rigor mode each run used, and a run whose record cannot be read is marked `no readable record` instead of counted as zero.
- **Spend at list price reads `~$` everywhere:** an amount at subscription list price, which no cap counts, is written `~$0.40` on every screen instead of `NOTIONAL~$0.40`.
- **Download the build you need:** the `.dmg` (macOS, signed and notarised), or the AppImage or the `.deb` (Linux, **unsigned**: the SHA-256 in `console-sha256sums.txt` is what proves the bytes, and that file is signed with the Sigstore bundle beside it).

### Known limits

- Launching needs Fugaro 0.11.2 or later; everything else in this release works with Fugaro 0.12.0, and the leased split and the by-mode breakdown appear once you run Fugaro 0.13.0, which is not released yet (until then the bar shows counted and headroom only and the Leased row reads `n/a`).
- The confirmation window's pause starts when the window is shown or focused; if macOS never reports either, Yes stays refused and Cancel is the way out.
- Halt fleet, Halt project and Reap are drawn but disabled: launching is the console's only write in this release.
- Windows and automatic updates come in a later release.
- The Fugaro Subscription Terms that the licence refers to may not be published yet.
