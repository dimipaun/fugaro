# Fugaro Console 0.127.0 "Zante"

Zante reads runs from the run index and draws the Coordinator from the orchestrators' own map. Lists and the
graph answer the same on a project with thousands of runs as on one with a few.

- **Runs, plan status and the graph read the index.** The Live list, the plan status and the Graph screen are
  answered from the project's run index, so what they cost no longer grows with the history.
- **The Coordinator shows the real map.** The tab draws the active orchestrators and their plan tasks from what the
  orchestrators wrote, and the placeholder data it used before is gone. A CLI too old to answer shows `n/a` with the
  cause.
- **Download the build you need:** the `.dmg` (macOS, signed and notarised), or the AppImage or the
  `.deb` (Linux). The Linux artifacts are unsigned: an AppImage is not code-signed, there is no Linux
  signing key and none is planned; the SHA-256 in `console-sha256sums.txt` is what proves the bytes, and
  that file is signed with the Sigstore bundle beside it.

### Known limits

- **The screenshot goldens have not been re-recorded** (the owner's Checks 710 and 712), so the recorded images
  still show earlier screens. CI skips the goldens, so nothing fails.
- **The console's unit tests can time out on a loaded machine.** They pass when run alone or with
  `--maxWorkers=2`.
- **There is no Windows download.** The Windows installer is unsigned and is packed at release time only,
  attached to nothing.
