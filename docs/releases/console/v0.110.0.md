# Fugaro Console 0.110.0 "Cherry"

The console is now its own release: open it and it finds your Fugaro installations and the `fugaro` binary on its own, so a first run needs no configuration.

- **A first run that sets itself up.** The console discovers your installations and resolves the CLI binary, and when something is missing it shows the page that tells you what to install or which command to run.
- **A review inbox.** Pull requests that are waiting for you to look at them are in one place, with who started each run.
- **Who started what.** Runs show who launched them, and Spend can be read by person as well as by repository.
- **A banner on development builds**, so a build made from source is never mistaken for a release.
- **Linux as well as macOS.** Download the `.dmg` (macOS, signed and notarised) or the AppImage or the `.deb` (Linux, **unsigned**: the SHA-256 in `console-sha256sums.txt` is what proves the bytes, and that file is signed with the Sigstore bundle beside it).

### Known limits

- **Windows is not available yet.** The route that runs the CLI inside a WSL distribution is built but switched off, and there is no Windows installer in this release.
- **Linux builds are unsigned**, as described above.
- **The plan graph is not shown yet.** Its data layer is in this release; the screen follows in a later one.
