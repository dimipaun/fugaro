# Fugaro Console 0.111.0 "Mango"

The console now reads the run lists that Fugaro 0.11.0 writes, so its runs and live views keep working after you upgrade the CLI.

- **Runs now show their rigor mode.** The run records written by Fugaro 0.11.0 carry a rigor block (the mode, and which layer set it); the console accepts it instead of dropping into its version-skew state.
- **Dependency updates.** The packaging tools (`@electron/fuses` 2.1.3, `electron-builder` 26.18.0) and the type definitions are updated; no fuse changes value.
- **Download the build you need:** the `.dmg` (macOS, signed and notarised), or the AppImage or the `.deb` (Linux, **unsigned**: the SHA-256 in `console-sha256sums.txt` is what proves the bytes, and that file is signed with the Sigstore bundle beside it).

### Known limits

- Windows is still not available; the WSL route stays off.
- The plan graph and the console's rigor-mode display are not in this release.
