# Fugaro Console 0.112.0 "Melon"

The console now lists every installation in its left rail, so you switch between projects in one click and see at a glance which one needs attention, and it shows each run's rigor mode.

- **Every installation in the left rail, no picker.** The console finds your installations on its own and lists all of them in the rail; it no longer opens a picker window before you can start. An installation that cannot be opened (or whose shared config is stale) carries a warning icon, and selecting it shows the issue in the main area, with the command that fixes it, instead of a dialog. The `+` button in the rail still adds one by hand.
- **The rigor mode of each run.** The Projects runs list has a MODE column, Live shows the mode as a chip on each row, and the run detail has a Rigor row.
- **Runs launched with `--plan-task` no longer break Live and Runs.** The console accepts the `plan_task` key that Fugaro 0.11.2 and later record for such a run, which an earlier console refused as an unknown field.
- **Download the build you need:** the `.dmg` (macOS, signed and notarised), or the AppImage or the `.deb` (Linux, **unsigned**: the SHA-256 in `console-sha256sums.txt` is what proves the bytes, and that file is signed with the Sigstore bundle beside it).

### Known limits

- The plan dependency graph screen and the coordinator's project view are not in this release.
- Automatic updates and Windows come in a later release.
