# Fugaro Console 0.122.0 "Strawberry"

Strawberry adds a seats panel to the Project tab, writes down what the console does when a licence key
has lapsed, and makes the Graph tab follow the coordinator's view as it changes, draw the project's
cross-plan edges in lanes of release boxes, and keep its cards at a size you can read. The seats panel
needs **Fugaro 0.21.0** or later, the release that prints `fugaro seats --json`; the lanes and the
cross-plan edges need **Fugaro 0.23.0** or later, the release whose `fugaro graph --json` carries the
project's roadmap record.

- **A seats panel on the Project tab, advisory only.** It draws the estimate `fugaro seats --json`
  publishes beside the seats the licence key carries, each figure marked as a reading (the estimate is
  a lower bound whenever the CLI could not count a member), and one warning sentence when the estimate
  is above the key's seats. It has no control and refuses nothing: seats are compared, never enforced.
  Against a CLI older than 0.21.0 the panel says which version it needs instead of asking.
- **Read-only after the grace period, with cancel kept.** When the licence key's own grace has run out,
  the console refuses two things in its main process before any child is started, **launching a run** and
  **editing a setting**, and answers with one sentence that names the Project tab's Licence key
  section. Every read, the console's own screens, cancelling a run and the key screen keep working, and
  a renewed key pasted during a session lifts the refusal on the next call. This build's licence keyring
  is still empty, so no key verifies yet and nothing is refused in practice (Known limits).
- **The Graph follows the coordinator's view.** The coordinator scope is fed by `fugaro graph --watch`,
  so a change in the stored view repaints the section without a refresh. Each source row carries the
  time its figures date from, and a source that answers with nothing keeps its last figures, drawn
  with the word "last read", rather than an empty panel.
- **Cross-plan edges in release lanes.** With the project's roadmap record the coordinator scope
  draws one lane per stream, each holding its release boxes in the record's own order (an empty box is
  still drawn) and the tasks nobody has placed, with a tab per stream. A task that depends on another
  plan's task carries a marker naming that task's stream and release box, and a record that names a
  task or release it no longer holds is marked as dangling rather than dropped. Orchestrator and
  local sources, which `fugaro graph` also reads from 0.23.0, can appear as their own source rows in the same scope.
- **A graph you can read.** A wide graph is no longer shrunk until its titles are grey blocks: cards
  keep at least three quarters of their width, and a graph wider than the panel scrolls sideways.
- **On a distribution, the environment view says whose credentials these are.** On the WSL route the
  environment view now says that the CLI uses the distribution's own credentials, that the login has
  to be run inside it, and that the console holds none, so `fugaro doctor` is what answers whether the
  CLI is signed in.
- **Download the build you need:** the `.dmg` (macOS, signed and notarised), or the AppImage or the
  `.deb` (Linux). The Linux artifacts are unsigned: an AppImage is not code-signed, there is no Linux
  signing key and none is planned; the SHA-256 in `console-sha256sums.txt` is what proves the bytes, and
  that file is signed with the Sigstore bundle beside it. There is no Windows download.

### Known limits

- **The seats panel needs Fugaro 0.21.0 or later; the lanes and cross-plan edges need 0.23.0.** Against
  a CLI older than 0.21.0 the seats panel says which version it needs, and a graph document that carries
  no roadmap record draws as it did before.
- **Nothing is refused for a lapsed key yet.** The lapse gate is in the build, and so is a verifier for
  the version 1 key (`fgk_`), but the verifier is not wired to the key screen and the production keyring
  is empty until the owner's signing keys exist, so no key verifies in a real build and every licensed
  release stays honour-based. Key enforcement arrives with the key service.
- The seat estimate is a floor, never a ceiling, and a person it cannot identify as one (a group, a
  domain, an account) is drawn as a label, not counted.
- The Graph's lane drawing is a reading rather than a picture of the dependencies between boxes: a
  cross-plan dependency is a marker on the task that needs it, not an edge.
- Windows comes in a later release.
- The Fugaro Subscription Terms that the licence refers to may not be published yet.
