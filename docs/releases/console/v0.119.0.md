# Fugaro Console 0.119.0 "Pomelo"

Console 0.118.0 showed the Coordinator's pull requests and the queue of things waiting on you, but you could not see a pull request's description, the jobs behind the fleet's totals or what the fleet had declared it was working on without a terminal, the totals waited on a slow read, and nothing on the Project tab said which models and routes the project could use. Pomelo fills in the Coordinator, adds a read-only Models panel to the Project tab, and makes crash reports readable. Most of it needs Fugaro 0.16.0.

- **The fleet's totals first, the jobs when you ask:** the Coordinator draws its totals strip from a quick summary read as soon as the tab opens, instead of waiting for the whole list of runs. Press **Load jobs** to see the last day's jobs under it; each row opens to show its details, and **Older 50** loads the next page. Nothing is read until you press it. The action queue now refuses a list of runs it cannot fully read and says so, rather than offering **Retry** or **Launch** from a row it did not understand.
- **A pull request's description, and what the fleet has declared:** open a pull request's row on the Coordinator to read its description, read once when you first open it. A read-only pane lists the intents each repository has declared and answers three questions: what is in flight, what collides, and which repositories have not been reconciled yet. When a section's read fails, its **Refresh** stays on screen and no stale "as of" time is left beside the error.
- **Models on the Project tab:** a read-only panel lists the project's routes and models: each route's kind, the models it serves, any fee it adds and which repositories may send data to it, and each model's route and prices. A price the catalogue does not have shows as `n/a`, never `$0.00`, and the catalogue says when it was last checked and whether it is stale.
- **Crash reports you turned on can now be read:** a report now names the console version it came from and carries what is needed to match it to that build's symbols, with file paths cut to the app's own and no user name. Crash reporting is still off unless you turn it on.
- **Download the build you need:** the `.dmg` (macOS, signed and notarised), or the AppImage or the `.deb` (Linux, **unsigned**: an AppImage is not code-signed, there is no Linux signing key and none is planned; the SHA-256 in `console-sha256sums.txt` is what proves the bytes, and that file is signed with the Sigstore bundle beside it). There is no Windows download.

### For operators

- **Upgrade the CLI to Fugaro 0.16.0 first.** The fleet totals, the job list and the Models panel need it: on an older CLI the console reads nothing for them and draws a sentence saying they need Fugaro 0.16.0. The pull request description and the declared-intents pane also need 0.16.0; on an older CLI they show the CLI's own refusal.
- On macOS, console 0.118.0 offers this update by itself: press **Restart to update** when the notice names 0.119.0. On Linux, download the AppImage or the `.deb` from this release's page.
- Crash reports become readable only once the console's debug symbols are uploaded. The upload step is staged at `docs/pending-workflows/console-release-symbols.yml`: the owner copies it into `.github/workflows/` and adds a `SENTRY_AUTH_TOKEN` secret to the `console-release` environment. Until both are done, release builds upload no symbols, and this release's build uploads none.

### Known limits

- The Models panel shows a route's host as the placeholder `<host>`, because the console never draws a machine name; the host is still readable inside the route's base URL beside it.
- The Models panel is read-only. Editing the project's settings from the console is the next release.
- Crash reports cannot be read against symbols until the symbol upload above is copied in and its secret is added.
- On the Project screen Kill, Revive and Add cap are drawn but disabled, Halt fleet, Halt project and Reap stay disabled, and the Graph inspector's Pause task is drawn disabled: launching is still the console's only write.
- The Caps today panel does not show per-repository compute spend yet.
- Launching needs Fugaro 0.11.2 or later, and the leased split on the cap bar needs Fugaro 0.13.0 or later.
- Windows comes in a later release.
- The Fugaro Subscription Terms that the licence refers to may not be published yet.
