# Fugaro Console 0.113.0 "Nectarine"

The console now draws every plan as a dependency graph next to its runs and shows the coordinator's view of your project, and it is the first console release under the console's own business licence instead of MIT.

- **A new licence, starting with this release.** Console 0.113.0 and later are under the Fugaro Enterprise Edition licence in `console/LICENSE.md`, not MIT. The source stays visible in the repository. Using the console for development and testing is free. Production use needs a subscription under the Fugaro Subscription Terms. Every console release up to and including 0.112.0 stays under the MIT licence it was released under. This release does not check for a licence key: compliance is on your honour, and key enforcement arrives in a later release.
- **The Graph screen.** A read-only dependency graph of every plan, with each task next to the runs working on it. You can reach every part of it from the keyboard. Its motion turns into a static style when your system asks for reduced motion, and it stays legible under forced colors.
- **The Coordinator tab.** A project view of every repository in the installation, read from the view the coordinator last stored, so it needs no GitHub App key. It is labelled as the last stored view, so it never reads as current; a repository whose stored view went stale says since when, and a repository the coordinator has not reached yet shows its runs instead.
- **Plan status and pull requests on Live.** The console reads `fugaro plan status`, and a live run's row shows its pull request number as soon as the run opens its draft. The Graph screen, the Coordinator tab and the pull request numbers need Fugaro 0.12.0 or later.
- **Download the build you need:** the `.dmg` (macOS, signed and notarised), or the AppImage or the `.deb` (Linux, **unsigned**: the SHA-256 in `console-sha256sums.txt` is what proves the bytes, and that file is signed with the Sigstore bundle beside it).

### Known limits

- Windows and automatic updates come in a later release.
- The Fugaro Subscription Terms that the licence refers to may not be published yet.
