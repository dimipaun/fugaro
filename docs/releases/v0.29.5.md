- `fugaro update` moves what your repositories' `fugaro.yaml` files declare (models, rigor, A/B rate, recipes, caps) into the project, and sets the project's `agent.auth` from them.
- `fugaro update --ask` asks which `agent.auth` the project takes when your repositories disagree.

### For operators

Run `fugaro update`. It prints one line per repository whose runs change before it writes.

### Known limits

- A project layer file that writes `defaults.agent` as a flow map (`{ auth: x }`) stops the lift with an error until it is rewritten in block style.
