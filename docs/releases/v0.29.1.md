- **`fugaro update` now completes on an installation that already runs the resident orchestrator.** 0.29.0's update stopped at the installation step with "calls a service that is not known and none is created with it" and left the policy, the rules, the credentials-service move and the image rebuilds undone; this release applies that step.

### For operators

`brew upgrade dimipaun/tap/fugaro`, then `fugaro update` again: an installation whose 0.29.0 update stopped at the installation step is brought to 0.29.0's state by this one, and nothing else changes.
