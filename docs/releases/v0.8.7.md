- The desktop console's release now builds on a fixed pipeline. Apple's notarisation and its ticket stapling run in a script that retries only the stapling when Apple's service drops the connection, which is what stopped the console from being published with 0.8.5. The console, a macOS app, is published as its own release, `console-v0.8.7`, as a draft that you publish after checking it.
- The CLI is otherwise identical to 0.8.6.

### For operators

1. Upgrade the CLI (`brew upgrade dimipaun/tap/fugaro`) and, in each repository checkout, run `fugaro upgrade` so the plugin pin follows it. Nothing needs to be re-run per installation: there is no change to an installation's cloud resources.
2. The console is a separate download from the `console-v0.8.7` release; it does not update itself. The site's console download buttons stay off until that release is published and the site's console flag is switched on.
