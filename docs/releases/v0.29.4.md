- **A Bitbucket repository's job image builds.** The clone step now names its build to the credentials service's proxy, which refused the call with a 403 on 0.29.3.
- **A launch gets its slip.** The credentials service refused every launcher's slip grant with a 403; the grant now carries the launcher's token where the service reads it.

### For operators

`brew upgrade dimipaun/tap/fugaro`, then `fugaro update`, then `fugaro image build sandbox-web` if it did not rebuild.
