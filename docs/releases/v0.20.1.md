- **The job images for this line are published.** v0.20.0's images were never built, because the image build broke on a change in the CI runner's BuildKit; the base, credentials and history images now build on a docker-container builder, and `fugaro update` on 0.20.1 can fetch them. Everything else in 0.20.0 is unchanged.
- **The base image build no longer mis-reads git-lfs's filter.** The step that rewrites `/etc/gitconfig` read the filter keys back after emptying the file; it now reads them first.
