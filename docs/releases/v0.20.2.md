- **`fugaro update` no longer refuses an installation that has a project catalog check.** The managed gate did not know the catalog check job's command, so the update stopped at the installation step with "runs a command the modules do not set". The gate now covers that command and also holds the job's spec to the run's own registry and service accounts.

### For operators

1. Upgrade the CLI and run `fugaro update` in each checkout, as for 0.20.1. An installation whose update was refused at the installation step by the message above now goes through.

### Known limits

- Everything in v0.20.0's known limits still stands: the cloud review is built and not admitted, repository-image removal and G3 to G13 are not in, and the credentials service is still opt-in.
